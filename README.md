## 📖 Overview

**THE CKA MASTERY BLUEPRINT** is a comprehensive, five-volume educational publishing and hands-on preparation system engineered to master Kubernetes cluster administration, advanced troubleshooting, and conquer the Cloud Native Computing Foundation (CNCF) and Linux Foundation **Certified Kubernetes Administrator (CKA)** examination on the first attempt.

Targeting the official Kubernetes **v1.31.x / v1.32.x** examination baseline with verified forward compatibility for **v1.33+**, this system eliminates the #1 cause of candidate failure: time-pressure and troubleshooting deficiencies under the 120-minute PSI remote desktop environment.

## 🚀 Quick Start: Running the Companion Labs

### 1. Prerequisites
* [Docker](https://docs.docker.com/get-docker/) installed and running.
* [Kind](https://kind.sigs.k8s.io/) (`v0.24.0+`) installed.
* [kubectl](https://kubernetes.io/docs/tasks/tools/) (`v1.31+`) installed.

### 2. Launch Local 3-Node Cluster
```bash
# Provision 3-node Kubernetes cluster (1 control-plane, 2 workers)
kind create cluster --config cka-mastery-blueprint-labs/setup/kind/kind-multi-node.yaml --name cka-cluster

# Verify cluster nodes
kubectl get nodes -o wide
```

### 3. Run Automated Lab Test Harness
```bash
chmod +x cka-mastery-blueprint-labs/scripts/verify-all-labs.sh
./cka-mastery-blueprint-labs/scripts/verify-all-labs.sh
```

## 🛠️ Zero-Deprecation Standard (Kubernetes v1.31+)

This Version 2.0 release adheres strictly to modern Kubernetes CLI standards:
* **`--record` is Permanently Removed:** Deprecated in v1.19 and removed in v1.26+. All rolling update revisions are managed via supported annotations:
  ```bash
  kubectl set image deployment/app nginx=nginx:1.27
  kubectl annotate deployment/app kubernetes.io/change-cause="Updated image to 1.27" --overwrite
  ```
* **Gateway API v1.1+ Standard:** Fully integrates `GatewayClass`, `Gateway`, `HTTPRoute`, and `ReferenceGrant`.
* **ReadWriteOncePod (RWOP):** Full coverage of GA single-pod persistent volume locking.
* **containerd via CRI:** Exclusive reliance on `crictl` and `/run/containerd/containerd.sock`.
